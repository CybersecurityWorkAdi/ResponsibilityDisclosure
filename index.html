What should I do if I find a security flaw, and how do identify one?

Security flaws are errors in a system which allow users or unauthorized/malicious people to access private or sensitive information, or take advantage of this security flaw to damage the system. Usually if you find a security flaw it would be of a company, occasionally an individual if you are using their site. Your first priority should be to report the security flaw to the company or individual in order for it to be fixed. If you have difficulty contacting the company, “NCSC” can help. NCSC is the National Cyber Security Centre. Policies related on what to do with this security flaw could potentially be found on a security.txt file on the site. Make sure your report is secure in order to prevent any harmful users from accessing it and finding the security flaw in order to exploit it.

What should I do if the company ignores me?

Contacting NCSC can help with anything related to a security flaw, so by contacting them you would likely be able to get a hold of the “vendor” (vendor in this context refers to the company/individual that manages/owns the site). While you are contacting NCSC, make sure that you avoid doing anything harmful to the site, which goes without saying but doing things such as installing malware, making changes to the companies data, copying anything, or accessing the system again unless you are missing any crucial information to help fix the security flaw. Other useful resources can include "https://www.cisa.gov/known-exploited-vulnerabilities-catalog" the known exploited vulnerabilities catalog by the CISA (Cybersecurity & Infrastructure Security Agency).

Password Attacks

What are they? Which kinds are there, and how do they work?

What is a password attack?

A password attack is when an attacker uses a password cracking method in order to access sensitive/private information.

What are the different kinds of a password attack?

  • Brute Force & Spraying

    • Brute force takes advantage of weak passwords using automated tools which can make multiple guesses in a very short period of time. Mainly by taking advantage of weak passwords and breaking through by using tools which are capable of testing every combination in a short period of time. Spraying attempts a small set of commonly used passwords until it works. These types of attacks are very easy to defend against simply just by having a creative/lenghty password.

  • Dictionary Attacks

    • Dictionary attacks are much more powerful compared to something like brute force which tends to be very weak. It takes advantage of common phrases using a predefined list, including some common letter combinations. These types attacks are also pretty easy to defend against as long as you use a unique password.

  • Credential Stuffing

    • Credential stuffing is usually when attackers use breached information and an automated tool in order to access sensitive information. You can defend against this by using trustworthy sites with high security in order to avoid any security breaches where your information is leaked.
